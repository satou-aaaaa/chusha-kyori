# 駐車禁止は何m？（chusha-kyori）

交差点・横断歩道・踏切・バス停・消火栓・火災報知機・駐車場の出入口などの場所を読んで、車をとめてはいけない範囲（その場所の中・1m・3m・5m・10m以内）を当てる1日5問の学習ゲーム。正解したら、停車もだめ（駐停車禁止）か、駐車だけだめ（駐車禁止）かも選ぶ。運転を習う人や、交通のきまりの学習に。

遊ぶ: <https://satou-aaaaa.github.io/chusha-kyori/>

- 中身は e-Gov 法令検索の道路交通法（<https://laws.e-gov.go.jp/law/335AC0000000105>）第44条（停車及び駐車を禁止する場所）・第45条（駐車を禁止する場所）に書いてあることだけです（2026-11-17 に読みました）。
- 説明は条文を、短く言いかえたものです。道路標識・標示で別に決まる場所、時間制限駐車区間、第45条第2項（右側の余地）、反則金・違反点数は省いています。公式の情報の代わりではありません。実際に車をとめるときは、その場所の道路標識・標示と、警察の案内で確かめてください。
- 停車もだめか駐車だけだめかは、第44条の場所か第45条の場所かで分けています。
